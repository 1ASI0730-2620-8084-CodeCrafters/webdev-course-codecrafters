# Fundamentos de Desarrollo Web

## Resumen del Curso
Este curso de 1 hora introduce a estudiantes de secundaria a la creación de sitios web sencillos con HTML y CSS. A lo largo de las lecciones se construye **una página web personal**: primero su estructura, luego su contenido, después su diseño y, al final, se revisan los errores más comunes. **¡No requiere descargas!** Solo abre tu navegador web.

**Duración total**: ~60 minutos
**Público objetivo**: Estudiantes de 12 a 17 años sin experiencia en programación
**Prerrequisitos**: Ninguno
**Herramientas necesarias**: **¡Solo tu navegador web!** (Chrome, Firefox, Safari, Edge). Todas las prácticas se hacen en JSFiddle, un editor en línea y gratuito.

**📂 Repositorio de código fuente**: [https://github.com/1ASI0730-2620-8084-CodeCrafters/webdev-course-codecrafters](https://github.com/1ASI0730-2620-8084-CodeCrafters/webdev-course-codecrafters)

## Secuencia de la lección

### Lección 1: ¿Qué es el desarrollo web? (5 minutos)
- **Descripción**: Descubre de qué están hechos los sitios web y por qué HTML y CSS son sus componentes básicos.
- **Enlace**: [Ver la lección](PENDIENTE-youtube-leccion-1)
- **Consejos clave**: Sitios web = Contenido (HTML) + Estilo (CSS). El navegador lee ese código y lo convierte en lo que ves.
- **Empieza a programar**: [Abrir JSFiddle](PENDIENTE-jsfiddle-leccion-1) 👈 **¡No necesitas registrarte!**
- **Código**: [inicial](https://github.com/1ASI0730-2620-8084-CodeCrafters/webdev-course-codecrafters/tree/main/starter-files/lesson1) · [resuelto](https://github.com/1ASI0730-2620-8084-CodeCrafters/webdev-course-codecrafters/tree/main/completed-examples/lesson1) · [guion](https://github.com/1ASI0730-2620-8084-CodeCrafters/webdev-course-codecrafters/blob/main/scripts/lesson1.md)

### Lección 2: Tu primera página HTML (10 minutos)
- **Descripción**: Aprende qué son las etiquetas, los elementos y los atributos, y crea tu primera página con un título y una presentación.
- **Enlace**: [Ver la lección](https://youtu.be/7ciLQob0Ebo)
- **Consejos clave**: Toda página tiene la misma base: `<!DOCTYPE html>`, `<html>`, `<head>`, `<title>` y `<body>`. Usa `<h1>` para el título y `<p>` para los párrafos.
- **Práctica**: [Clic para programar en JSFiddle](PENDIENTE-jsfiddle-leccion-2) 👈 **¡No necesitas registrarte!**
- **Código**: [inicial](https://github.com/1ASI0730-2620-8084-CodeCrafters/webdev-course-codecrafters/tree/main/starter-files/lesson2) · [resuelto](https://github.com/1ASI0730-2620-8084-CodeCrafters/webdev-course-codecrafters/tree/main/completed-examples/lesson2)

### Lección 3: Agrega contenido a tu página (10 minutos)
- **Descripción**: Agrega subtítulos, listas, imágenes y enlaces para que tu página tenga más información.
- **Enlace**: [Ver la lección](PENDIENTE-youtube-leccion-3)
- **Consejos clave**: `<h2>` para subtítulos, `<ul>` y `<li>` para listas, `<img src="..." alt="...">` para imágenes y `<a href="...">` para enlaces. El atributo `alt` describe la imagen para quien no puede verla.
- **Práctica**: [Clic para programar en JSFiddle](PENDIENTE-jsfiddle-leccion-3) 👈 **¡No necesitas registrarte!**
- **Código**: [inicial](https://github.com/1ASI0730-2620-8084-CodeCrafters/webdev-course-codecrafters/tree/main/starter-files/lesson3) · [resuelto](https://github.com/1ASI0730-2620-8084-CodeCrafters/webdev-course-codecrafters/tree/main/completed-examples/lesson3)

### Lección 4: Introducción a CSS y estilos sencillos (12 minutos)
- **Descripción**: Dale estilo a tu página con colores, fuentes, bordes y espacios, y aprende a centrar el contenido.
- **Enlace**: [Ver la lección](PENDIENTE-youtube-leccion-4)
- **Consejos clave**: Una regla CSS tiene un selector, una propiedad y un valor: `h1 { color: purple; }`. Con `color`, `font-family`, `text-align: center` y `border` cambias el color, la fuente, centras el contenido y agregas bordes. En JSFiddle escribes el CSS en su panel y se aplica solo.
- **Práctica**: [Clic para aplicar estilo en JSFiddle](PENDIENTE-jsfiddle-leccion-4) 👈 **¡No necesitas registrarte!**
- **Código**: [inicial](https://github.com/1ASI0730-2620-8084-CodeCrafters/webdev-course-codecrafters/tree/main/starter-files/lesson4) · [resuelto](https://github.com/1ASI0730-2620-8084-CodeCrafters/webdev-course-codecrafters/tree/main/completed-examples/lesson4)

### Lección 5: Crea tu página de perfil personal (15 minutos)
- **Descripción**: Junta todo lo aprendido y construye una página de perfil con tu presentación, tus pasatiempos, una imagen y un enlace.
- **Enlace**: [Ver la lección](PENDIENTE-youtube-leccion-5)
- **Consejos clave**: Primero organiza el contenido con HTML y después dale estilo con CSS. Guarda tus cambios y revisa el resultado después de cada paso.
- **Proyecto Final**: [Crea tu perfil en JSFiddle](PENDIENTE-jsfiddle-leccion-5) 👈 **¡Guarda y comparte!**
- **Código**: [inicial](https://github.com/1ASI0730-2620-8084-CodeCrafters/webdev-course-codecrafters/tree/main/starter-files/lesson5) · [resuelto](https://github.com/1ASI0730-2620-8084-CodeCrafters/webdev-course-codecrafters/tree/main/completed-examples/lesson5)

### Lección 6: Consejos y errores comunes (8 minutos)
- **Descripción**: Aprende a encontrar y corregir los errores más comunes de principiantes, y descubre dónde seguir aprendiendo.
- **Enlace**: [Ver la lección](https://youtu.be/9K_EQx0b0cY)
- **Consejos clave**: Cierra cada etiqueta que abres, revisa que cada regla CSS tenga sus llaves `{ }` y su punto y coma `;`, y valida tu código en [validator.w3.org](https://validator.w3.org/). Sigue aprendiendo en MDN Web Docs.
- **Práctica**: [Corrige los errores en JSFiddle](PENDIENTE-jsfiddle-leccion-6) 👈 **¡No necesitas registrarte!**
- **Código**: [inicial](https://github.com/1ASI0730-2620-8084-CodeCrafters/webdev-course-codecrafters/tree/main/starter-files/lesson6) · [resuelto](https://github.com/1ASI0730-2620-8084-CodeCrafters/webdev-course-codecrafters/tree/main/completed-examples/lesson6)
